Validation — version 0.1.0 — 2026-10-22

Environment and scope
- Docker on a Linux amd64 host; supplied Dockerfile and bundled source context.
- python:3.12-slim-bookworm from docker.1ms.run; Python 3.12.15 in the tested image.
- Python packages from the explicitly approved Aliyun domestic mirror.
- Tests used isolated containers and loopback SSH/HTTP fixtures. The existing
  Sentinel service was not restarted or replaced. No production target scanned.

Passed
- Official Sentinel v2.1.6 manifest parser: valid, 19 tools, source repository set.
- Actual docker build, dependency imports, mitmdump 11.0.2 startup/version output.
- Both isolated Frida Python runtimes import: 17.2.17 and 16.7.19.
- Container Python suite: 80 discovered, 79 passed, 1 skipped because the runtime
  image intentionally has no Node (Node is not needed by the plugin at runtime).
  The skipped case executes the embedded dump JavaScript against binary fixtures;
  all 14 dump tests, including that case, passed separately with Python and Node.
- SSH fixtures cover actual authentication, SFTP, direct/reverse forwarding,
  host-key rejection before authentication, bounded cleanup when the peer omits
  cancel-forward replies, and password fallback only when explicitly configured.
- Real mitmdump + reverse SSH + HTTP origin integration covers capture, request
  and response mutation, rule clearing, oversized/streaming response handling,
  natural completion, cancellation and tunnel/process cleanup.
- HTTP API tests cover POST method/Content-Type/body preservation, baseline and
  identity header merging, independent cookie jars, redirects, truncation and
  rejection of invalid headers before any network request.
- MCP HTTP tests include initialization, tools/list, tools/call, notifications,
  errors as MCP results, IPA chunk import/analysis/artifacts, cancellation and
  interrupted state after restart.
- 31 UI event tests verify actual SDK arguments and UI state transitions.
  Official SDK/base CSS byte identity, safe rendering and overflow checks pass.
- 6 Hook tests execute production hooks.js against a simulated Frida API,
  covering actual byte replacement and accurate sampling/mutation evidence.
- Container smoke checks: health within the 20-second deadline, 19 live tools,
  actual tool execution, offline/error state, all six UI resources GET/HEAD,
  traversal and direct-browser-origin rejection, clean exit without OOM.

Resolved during acceptance
- TUNA returned HTTP 403; the user approved Aliyun and both Dockerfile default
  and manifest build.args now use it. No direct PyPI fallback.
- mitmproxy/passlib failed with bcrypt 5.0.0; requirements pin bcrypt 4.0.1.
- Proxy flow-count reader now closes its file explicitly.
- The smoke fixture was corrected to distinguish offline cached status from an
  explicit refresh: refresh on an unconnected device correctly returns an error.

Not verified / do not infer
- No real iPhone, target App, jailbreak, Frida injection, runtime decryption or
  target API was exercised. Dump/Hook fixtures do not establish device support.
- No completed install or rendered iframe test inside the live Sentinel console.
  Contract validation uses its unmodified v2.1.6 parser and official SDK.
- Only Linux amd64 Docker was built; ARM64 container compatibility is unverified.
- Successful runtime probing is not an assurance of attachment on every App.
  See README for capture, encryption, dump and jailbreak capability limits.
